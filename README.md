# 🌍 GDG Solution Challenge Project

This project was created as a part of the **Google Developer Group (GDG) Solution Challenge**, where developers build solutions aligned with the United Nations’ Sustainable Development Goals (SDGs).

The aim of this web project is to address real-world challenges through a simple, accessible, and interactive interface.
